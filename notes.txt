State
- filtered hospitals (initialized to full hospital at conversation start)

util (filteredHospitals) -> (unique names, locations, actions)


Information Node:

Filter node
- uses util to get unique names, locations, and actions
given currently filtered hospitals

- based on user messages, outputs any name, location, or
action that has been specified using a structured output for each that is limited to what's in unique names, locations, and actions

- Filters remaining filtered hospitals in state based on that output

- If only one item remains in filtered hospitals -> route to ProposalNode

- Otherwise route to AskNode

ProposalNode
- Proposes the hospital with all details (streams back to live agent)

Ask Node
- Looks at remaining hospitals and asks for more filters from the user (streams back to live agent)
